# 刷新后的设置与部署记录

- 管理员 QQ、私聊白名单、群白名单保存到桥接的 config.json；页面加载时由本机接口重新读取。
- 未保存的表单仅在当前标签页 sessionStorage 保留草稿，点击“保存设置”才会应用到桥接。关闭标签页或清理站点数据可能清除草稿。
- 部署记录保存在 data/state/agent-deploy.json，最多保留最近 10 次任务，每次最多 200 条事件。设置 QQBOT_JOBS_FILE 时，部署记录跟随该文件的目录。
- 页面刷新恢复最新记录；市场服务重启后保留历史，但中断的任务不会自动执行，需重新点击一键部署核查。历史结果不代表当前运行状态，当前状态请查看运行监控。
- QQ 自动接入与空间写入测试的授权不恢复勾选；已保存的自动接入配置、上次空间测试结果单独回显。
- 设置读取接口限本机、同源、已登录请求；不返回桥接 token 或模型 API Key。
- 卡片主状态显示“已启用”“已配置”及明确故障，检查过程放入“查看诊断”。启用状态不等于已实际调用成功。

回归验证：node scripts/test-deploy-agent.mjs、node scripts/test-lab.mjs。浏览器另验草稿刷新、保存刷新、服务重启、历史恢复、授权不重放、手机布局及脚本错误。
